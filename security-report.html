P1-2 escapeHtml / escapeAttr 转义函数 XSS 防护
新增两个核心安全函数，覆盖所有渲染上下文： 
escapeHtml — 用于 innerHTML 上下文（<, >, & 转义）
function escapeHtml(str) {
  return String(str)
    .replace(/&/g, '&')
    .replace(//g, '>');
}

escapeAttr — 用于 HTML 属性值上下文（含 ", ' 转义）
function escapeAttr(str) {
  return String(str)
    .replace(/&/g, '&')
    .replace(//g, '>')
    .replace(/"/g, '"')
    .replace(/'/g, ''');
}
